# design_system_exemplo

Esse é um projeto para mostrar os componentes do Design System da Get

## Getting Started

Esse projeto usa a PUB storybook_flutter para poder relizar a exibição de exemplo.

## Testes

Para relizar os teste no storybook_test basta executar o comando abaixo:
    - flutter test --update-goldens --tags=storybook

Após isso será gerada uma pasta com os erros. Caso você precise testar em outro dispositivo basta alterar a lista no arquivo.
